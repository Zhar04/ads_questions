# inbox — новые найденные вопросы

Кидай сюда свои находки (из PDF, конспектов и т.п.) текстом — в файлах `.txt` или `.md`.

**Формат:** один вопрос = один абзац; разделяй вопросы **пустой строкой**. Варианты ответов
можно вставлять прямо в абзац — они помогают поиску.

Пример файла `nayden.txt`:

    Квадратичная сложность алгоритма в О-нотации
    A) O(n)  B) O(n^2)  C) O(log n)

    Сложность бинарного поиска в отсортированном массиве

Затем проверка на дубликаты (или просто скажи Claude «проверь inbox»):

    node tools/check-new-questions.mjs

По каждому вопросу покажет: 🔴 вероятный дубликат / 🟡 похоже (проверить) / 🟢 новый —
со ссылками на ближайшие вопросы банка и процентом совпадения. В банк добавляются
**только реально новые** вопросы (с правильным ответом и нормальным разбором).

> Содержимое этой папки **не** коммитится в git (кроме README) — это твоя локальная «входящая».
